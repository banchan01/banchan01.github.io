Built a full-stack English learning platform to address personal language learning challenges, covering from **React.js** frontend and **Ruby on Rails** backend to **Docker**-based deployment.

<br/>

## What I Did

- **Architected the entire project**: defined the problem, designed the learning methodology, and planned the solution.
- Designed **database schemas** and implemented **Redis caching strategies** for efficient API usage.
- Developed a custom **Telegram-based authentication** system.
- Upgraded quiz generation logic from Levenshtein Distance algorithm to **Gemini API**.
- Implemented **debouncing** to minimize redundant API calls and optimize token consumption.

<br/>

## Insights

- **Redux** significantly simplifies state management for complex features in frontend development.
- **Solo ownership** teaches the weight of architectural decisions—thoughtful planning directly impacts project success.
- Effective **caching strategies** are essential for optimizing performance and reducing external API costs.
